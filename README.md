# HTML, CSS & JavaScript Projects

A collection of small front-end projects built with HTML, CSS, and JavaScript.

## Projects

- `calc` — Calculator
- `clock` — Digital clock
- `counter-project` — Counter
- `dice-rolling` — Dice rolling simulator
- `interest-cal` — Interest calculator
- `number-guess` — Number guessing game
- `paperScissors` — Rock, paper, scissors game
- `password` — Password generator
- `random-number` — Random number generator
- `stopwatch` — Stopwatch
- `temprature-conversion` — Temperature converter

## How to Run

Open any project folder and open its `index.html` file in a web browser.

Example:

```bash
cd clock
open index.html
```

## Technologies

- HTML
- CSS
- JavaScript

## Purpose

These projects were created to practice core JavaScript concepts, DOM manipulation, events, and basic front-end development.
